# TradeFlow Backend

## Run

1. Install Node.js.
2. Install MongoDB Community Server and MongoDB Compass.
3. In MongoDB Compass, connect with:
   `mongodb://127.0.0.1:27017`
4. Copy `.env.example` to `.env` and set your values. For a local MongoDB server, use:
   `MONGO_URI=mongodb://127.0.0.1:27017/tradeflow_erp`
5. In this folder run:
   `npm install`
6. Start the backend:
   `npm run dev`

The API runs on `http://localhost:5000`.
