# TradeFlow Backend

## Run

1. Install Node.js.
2. Install MongoDB Community Server and MongoDB Compass.
3. In MongoDB Compass, connect with:
   `mongodb+srv://minnale3006:meena3006@cluster0.rg1k9a9.mongodb.net/tradeflow_erp`
4. Copy `.env.example` to `.env` and set your values. For a local MongoDB server, use:
   `MONGO_URI=mongodb+srv://minnale3006:meena3006@cluster0.rg1k9a9.mongodb.net/tradeflow_erp`
5. In this folder run:
   `npm install`
6. Start the backend:
   `npm run dev`

The API runs on `https://master-export-backend-s63k.onrender.com/`.
